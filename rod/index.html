Acesso aos dados da Rod

O primeiro passo, antes de qualquer automação: como eu entro em cada sistema.

Preparado por Fábio Borges, Me Ensina AI, a partir da nossa conversa. A/C Luiz Tabet.
O ponto de partida

Por que isso vem primeiro

Toda a automação depende de uma coisa só: eu conseguir acessar o dado que cada sistema de vocês gera. Toda ferramenta que a gente for usar precisa ter uma porta de entrada pros dados, o que a gente chama de API. Com essa porta, meus agentes entram e puxam a informação na hora que precisam. Sem ela, a gente combina outro caminho. Por isso, antes de falar de qualquer automação, eu preciso mapear como eu entro em cada sistema de vocês.

O sistema pode estar todo automatizado, mas por baixo ele alimenta um banco de dados. É esse banco que eu preciso acessar.

Os 3 jeitos

Os 3 jeitos de acessar o dado

Do melhor pro possível.

Ideal

Acesso direto por API

Eu entro no sistema e puxo o dado na hora que precisar. Tecnicamente isso se chama fazer um GET. É a forma mais segura de não errar dado.

Quando não há API

Envio automático diário

O sistema manda todo dia, num horário fixo, um arquivo com tudo que aconteceu no dia anterior pra um email. Meu agente lê esse arquivo de manhã e organiza sozinho. Foi assim que resolvi a compilação de dados de mais de 70 operadoras de seguro: um email diário com o arquivo do dia anterior, e o agente às 6h montando tudo.

Último caso

Coleta manual

Alguém baixa o arquivo. A gente evita, mas funciona.

A lista de apuração

O que eu preciso que vocês apurem agora

Comece pela Valet.

Prioridade · Valet primeiro

Valet

É o coração da operação (gestão, BI e as câmeras LPR que leem as placas). Da Valet eu preciso de duas coisas:

A documentação da API REST. Eles não têm API pública, mas têm uma API REST bem estruturada.

A liberação de um acesso pra eu fazer as consultas (os GET) e, se possível, um ambiente de teste (sandbox) pra eu montar o meu ambiente.

Depois da Valet, na sequência, o mesmo raciocínio pros outros sistemas. Pra cada um a pergunta é a mesma: onde o dado cai, tem API (me manda a documentação), libera o acesso; e se não tiver API, dá pra automatizar aquele envio diário?

A volta

Como o dado volta pra vocês

Do mesmo jeito que eu entro, eu devolvo. O relatório chega no formato que vocês quiserem: planilha, email ou uma mensagem no WhatsApp, no horário que definirem. O destino também é combinado com vocês.
